# Pixal3D railgun at 1536

Real GLB exported on Skynet using Pixal3D, not a concept render. Produced with trellis.cpp v0.8.1 Vulkan on one Intel B70, seed 42, 12 steps, 1536 geometry and 2048 PBR atlas. The original input is reference.png, and preview.png is a browser screenshot of the actual GLB. The original GLB file is retained unchanged; see manifest.json for provenance, SHA-256 and measured runtime/VRAM. No game optimization or rigging is implied.
