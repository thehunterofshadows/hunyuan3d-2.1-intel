# Portable Pinball V1.15 — M6 modular captive-nut feet

Change ONLY the feet from V1.14; preserve all previous configurations. See the public V1.15 README for assembly and print-first test instructions. M6x30 bolts couple 20-mm segments; M6x50 bolts couple 40-mm segments. Side-fed M6 metal nuts, alternating A/B vertical channels, and a central M6 nut for the commercial swivel pad. M4 floor fasteners are unchanged.
