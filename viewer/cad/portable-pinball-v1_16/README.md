# V1.16 — Tool-free M6×30 bolt-and-nut sections

Print-first version. Each 45 mm twist section has three prints: hex core, stepped locking key, and hexagonal snap sleeve. Real M6×30 hex-head bolts and M6 metal nuts; no printed M6 threads. Source and tests in this directory, assembly instructions in `assets/portable-pinball-v1_16/README-v1_16.md`. Earlier versions remain untouched.
