# Portable Pinball V1.17 — M6 connectors, M8 rubber feet

The 45 mm universal M6 sections and M6-mounted cabinet receivers remain as in V1.16. Only the last (bottom) 45 mm module per foot is replaced by a dedicated 55 mm M8-terminal variant with the same M6×30 male connector, printed key and snap sleeve above; the bottom houses a nominal 13 mm across-flats standard M8 metal nut in an 8 mm-deep side-entry pocket, plus a 21 mm-deep blind clearance bore for the purchased M8 swivel foot stud. No printed threads. Previous versions untouched. Physical fit and load testing required.
