# V1.18 — Slide-in nut retention clips + repaired M6 female bore

New M6-to-M6 spacer bores from underside (11.3 mm) correct the V1.17 blocked screw-on connection. One light PETG snap-in keeper closes each sideways nut opening: 6 M6 keepers (4 receivers, 2 upper rear spacers), 4 M8 keepers (all 55 mm terminals). Keepers are not structural and only retain loose nuts before bolt engagement. All earlier versions preserved. Test on small fit kit before supporting a populated cabinet.
